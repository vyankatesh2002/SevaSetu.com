# Assets / Fonts

Place self-hosted fonts here (WOFF2 format recommended) for offline usage.

Currently SevaSetu loads fonts via Google Fonts CDN:
- Inter
- Noto Sans Devanagari (Marathi support)

To self-host, download the font files (e.g. `inter.woff2`, `noto-sans-devanagari.woff2`)
and reference via `@font-face` in `assets/css/style.css`.
